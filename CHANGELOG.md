# История изменений

## Не выпущено

Изменения следующего релиза будут добавлены сюда.

## 3.4.0 — 2026-10-13

### Совместимость

- Минимальная версия Dart повышена с 3.0 до 3.12; поддерживается Dart 3.x.
- Обновлены зависимости: analyzer 14.5.0, source_gen 4.3.0, build_test 3.5.21, build_runner 2.16.2 и test 1.33.0.

### Исправления

- Исправлено экранирование строк из окружения в генерируемом Dart-коде.
- Обновлена интеграция генератора с современными API analyzer и source_gen.
- Добавлены проверки аннотаций, nullable-полей, значений по умолчанию и генерации.

### Документация и выпуск

- Подготовлены инструкции для репозитория, обоих пакетов и примера.
- Описаны чтение окружения при генерации, сброс кэша и поддерживаемые типы.
- Добавлен GitHub CI: анализ, тесты, проверка форматирования и генерация примера.
- Выпуск по тегу создаёт GitHub Release с заметками из CHANGELOG и архивами исходников каждого пакета.
